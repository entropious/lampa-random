# Случайное — плагин для Lampa

Плагин подбирает случайный фильм или сериал и открывает его карточку. Одной
кнопкой, без листания каталога.

## Установка

Настройки → Расширения → Добавить плагин, и вставить ссылку:

```
https://entropious.github.io/lampa-random/random.js
```

## Что появляется

**Две кнопки в шапке** — отдельно фильмы, отдельно сериалы, чтобы «пощёлкать»
одно, не получая вперемешку другое.

- Внутри категории кнопка выбирает случайное **из неё**, по всем её страницам,
  а не только из того, что видно на экране.
- На главной, где своего списка нет, — из всего каталога TMDB.

**Пункт «Случайное» в левом меню** — экран с фильтрами: тип, жанр, диапазон лет,
минимальный рейтинг, и кнопка «Показать случайное». Фильтры действуют только на
этот экран; кнопки в шапке всегда работают в простом режиме.

**Кнопка трейлера на карточке** — сразу после «Смотреть». Открывает поиск на
YouTube по английскому названию плюс «trailer».

## Что попадает в выборку

По умолчанию — фильмы и сериалы 2000 года и новее, с оценкой от 6 и достаточным
числом голосов, чтобы это не был совсем никому не известный тайтл. Порнография и
дошкольные мультфильмы отсеиваются.

Такие ограничения оставляют около 7 900 фильмов и 3 500 сериалов. Это важно:
TMDB отдаёт максимум 500 страниц, и оба набора в этот предел укладываются — то
есть выпасть может **любой** тайтл из отобранных, а не только первая тысяча
самых популярных.

Фильтр по возрастному рейтингу намеренно не используется: в TMDB он заполнен
примерно у 60% каталога, и включение такого фильтра молча выбросило бы остальное.
Дошкольное отсекается по сочетанию жанров «семейный» + «мультфильм» — уходят
«Тачки», остаётся «Гарри Поттер».

## Про запросы к TMDB

Плагин не ходит в сеть на каждое нажатие. За один заход он забирает пять
случайных страниц, перемешивает их и раздаёт 20 нажатий из этого пула. Размер
каталога запрашивается один раз. Пул хранится в настройках Lampa и переживает
перезагрузку, обновляясь раз в неделю.

Пять страниц берутся не ради экономии, а ради разнообразия: одна страница — это
срез каталога по популярности, и 20 подряд из неё дали бы одинаково
раскрученные тайтлы.

## Совместимость

Работает через встроенный в Lampa клиент TMDB, поэтому уважает ваши настройки
прокси и ключа. Интерфейс собран из родных компонентов и спрайтов, управление с
пульта поддерживается.
